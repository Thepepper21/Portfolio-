# Thepepper21 — Minimal Developer Portfolio

## Files
- `index.html` — semantic page structure and portfolio content
- `styles.css` — responsive layout, theme variables, animations and visual styling
- `script.js` — theme toggle, mobile nav, scroll progress, scroll reveals, active-link highlight, hero parallax, current year

## Preview locally
Open `index.html` in your browser, or open this folder in VS Code and use a local preview extension.

## Personalize before publishing
- Confirm your GitHub profile URL in `index.html` (`https://github.com/Thepepper21`).
- Replace `hello@example.com` with the email address you want to publish.
- Replace the sample project descriptions with real projects, screenshots, your contribution, and working links.
- Review the skills list so it accurately reflects what you are learning and can discuss.
- Check the site on desktop and mobile.

## Publish with GitHub Pages
1. Sign in at https://github.com and create a **public** repository named `portfolio`.
2. Upload the contents of this folder (not just the ZIP). Keep `index.html`, `styles.css`, and `script.js` at the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then click **Save**.
6. Wait for the publishing job. Your website will usually be at `https://YOUR-USERNAME.github.io/portfolio/`.
7. Open the live URL in a private/incognito window and on your phone. Test navigation, theme toggle, GitHub links, and contact email.
8. To update the site later, upload the changed files and commit them to the same repository.

Only publish information and images you are comfortable making public. GitHub Pages serves static files; the email link opens the visitor's configured email app and does not submit a form.
